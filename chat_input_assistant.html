Chat Input Assistant

プロフィール・会話メモ・返信候補を管理する試作版

入力アシスタント

このアプリはChatGPT本体とは別の独立した画面です。ここで作った文章をコピーしてChatGPTに貼り付けてください。

{user} プロフィール

プロフィールはこのブラウザ内に保存されます。

会話履歴

過去の会話をテキストで追加するか、JSONファイルを読み込めます。ChatGPTのエクスポートJSONは形式が複雑なため、この試作版ではまずテキスト貼り付けを推奨します。

プライバシー：この試作版はプロフィール・履歴をブラウザのlocalStorageに保存します。AI APIへの送信はまだ行いません。Safariの履歴消去やサイトデータ削除で消える場合があるため、定期的に書き出してください。
